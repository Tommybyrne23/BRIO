Create `lib/demo/` as the single deterministic source for a synthetic persona and 14-day fixture anchored to a supplied ISO local date. Use stable IDs and no random values. Include training sessions/sets, steps, active energy, sleep duration, ordinary heart-rate trend, manual nutrition totals, one check-in, preferences, consent, source states, nine metrics, and a current bounded decision. Implement these exact scenarios: normal evidence, specialist disagreement, signal revoked, missing nutrition, stale helper, model timeout, and escalation. Escalation must use action/status Escalate/escalated and block generated-session controls. Model timeout is an unavailable state, not a fake live fallback. Make all five actions reachable across the scenario set.

Add a deterministic prototype policy function that only accepts consent-filtered metric evidence and emits bounded proposals. It is explicitly a demo policy, not a validated health algorithm. Add tests proving same anchor/scenario yields byte-equivalent output; different scenarios yield the documented states; revoked signals are excluded and labelled not being read; no model key is required.

Provide two adapters sharing the same DTOs: (1) a browser-local fixture store for guest/offline rehearsal, persisted under a versioned localStorage key and resettable without touching server data; and (2) a guarded authenticated backend demo reset endpoint or seed command that operates only when `BRIO_DEMO_MODE=true` and the authenticated account is explicitly marked/recognized as a demo account. Never let backend reset target another account or silently activate for a failed live request. Add `BRIO_DEMO_MODE` to `.env.example` without a secret value.

The browser-local adapter must support reset, scenario selection, consent changes, decision accept/override, manual-log mutation, and session completion so P05-P11 can use it without duplicated mock logic. Mode switching clears account-scoped browser state. Expose no unlabelled simulated status and never write fixture data into Apple Health rows for a real account.
